Learn Intro to Machine Learning with Phoebe

Your first models, and how to know they are any good.

Two tracks, one running brand. The 6-session leader track teaches executives, PMs, and marketers what machine learning can and cannot do, how to read a model's report card without being fooled by a big accuracy number, and how to commission and govern an ML project - no code. The 10-session builder track takes practitioners through scikit-learn end to end: the sacred train/test split and the leakage trap, a first classifier and a first regressor, over- and under-fitting, the bias-variance tradeoff, cross-validation and tuning, the metrics that actually matter, and pipelines that keep you honest - finishing with a model-comparison capstone. This is the middle link in the Data Science ladder: statistics gave you the math, this gives you the models, experimentation gives you cause. Learn it all on Lumen Skincare.

The leader track 🤝 · for execs, PMs & marketers · 6 x 45 min · no code

A model is only as trustworthy as the reading you give it. This track teaches you to tell a real ML use case from a fad, to read a confusion matrix and an ROC curve, to catch the accuracy paradox before it fools your team, and to commission ML work responsibly - all without opening a notebook. A friendly on-ramp for LinkedIn readers, too.

🧭 Leader session 1 · start here

What ML actually is (and isn't)

Machine learning vs rules and dashboards, the three kinds of learning, prediction vs causation, and when NOT to use ML. The workflow every model follows, in plain language.

▶ Start hereNo code 📉 Leader session 2

How a model learns, and how it goes wrong

Learning from examples, the train/test idea, and the two ways every model fails - overfitting and underfitting - plus the bias-variance tradeoff, seen live, with no math to do.

Over/underfit 🧱 Leader session 3

The data is the model

Features and labels, garbage-in-garbage-out, and data leakage - the silent killer where a feature secretly contains the answer. Why more columns is not more signal.

Data & leakage 🩺 Leader session 4

Reading a model's report card

The accuracy paradox, the confusion matrix, precision vs recall, ROC-AUC, and RMSE in dollars - what every model metric means and which one to ask for. Threshold as a business choice.

Metrics 🔗 Leader session 5

Prediction is not proof

The model zoo at a glance - regression, trees, ensembles, neural nets, clustering - and the line every leader must hold: a model predicts, it does not prove cause. The bridge to experimentation.

Model zoo ⚖️ Leader session 6

Putting ML to work responsibly

The lifecycle after launch - monitoring and drift - fairness and bias, buy vs build, and the questions to ask your data team. Capstone: read a Lumen model card like an exec.

The builder track 🛠️ · for practitioners · 10 x 45 min · Python + scikit-learn

For DA, DE, DS, and anyone who needs to actually train and judge a model. One running brand - Lumen Skincare - carried across every session: simulate it, split it, fit a first classifier and a first regressor, diagnose over- and under-fitting, cross-validate, measure it honestly, pipeline the preprocessing to kill leakage, and finish by comparing models and picking one. Built with scikit-learn, numpy, and pandas.

⚙️ Builder session 1 · start here

Setup and your first dataset

scikit-learn, pandas, numpy - and the Lumen dataset built once with seed 42 (reused all course long). Meet the fit / predict estimator API that every model shares.

▶ Start herePython ✂️ Builder session 2

The train/test split (and the leakage trap)

train_test_split, stratify for imbalanced targets, and the rule you never break: fit on train only. The scaler-on-test disaster, shown in real numbers.

Split it right 🚀 Builder session 3

Your first model, end to end

LogisticRegression to predict who converts - fit, predict, predict_proba, first accuracy read - and the moment the accuracy paradox appears on a 3.2% base rate.

First classifier 📉 Builder session 4

Over- and under-fitting

A DecisionTree at rising max_depth, train vs test score, and the U-shaped test-error curve - bias and variance made concrete. The single most important picture in ML.

The U-curve 🎚️ Builder session 5

Bias-variance and regularization

The tradeoff formalized, then Ridge and Lasso - how an L2 or L1 penalty dials model complexity down and why Lasso can zero a feature out entirely.

Regularize 🔁 Builder session 6

Cross-validation and tuning

cross_val_score (5-fold), mean ± std, and GridSearchCV plus the validation curve - how to pick max_depth honestly, without ever touching the test set.

k-fold CV 🩺 Builder session 7

Classification metrics in depth

confusion_matrix, precision / recall / F1, classification_report, roc_auc_score, and the precision-recall curve - and moving the threshold to trade one error for the other.

Judge a classifier 📐 Builder session 8

Regression metrics + the model

LinearRegression on order value, MAE / MSE / RMSE / R², the predict-the-mean baseline, and single vs multi-feature - watch R² climb from 0.36 to 0.45 as you add signal.

Judge a regressor 🧱 Builder session 9

Feature prep and Pipelines

ColumnTransformer with OneHotEncoder and StandardScaler, wrapped in a Pipeline that kills leakage for good - plus coef_ and feature_importances_, and exposing session_hour as noise.

Pipelines 🏁 Builder session 10

Capstone: compare models

Put it together - logistic vs tree vs random forest, picked by CV, scored once on held-out test, written up as a model card. Then a short KMeans segmentation taste that tees up what comes next.

Try the ML playground 🎛️

Three live tools, no install, seeded from Lumen's real numbers. Split the data, slide a tree from underfit to overfit, and move a classifier's threshold to watch the accuracy paradox in action - the same tools are embedded in the sessions that teach them.

One brand, both tracks. Every session works on Lumen Skincare - a synthetic $18M direct-to-consumer skincare label reused from the statistics and experimentation courses. We build two models on it: a classifier for whether a checkout session converts (a ~3.2% base rate, so the accuracy paradox is unavoidable) and a regressor for how large the order will be (mean ~$74, right-skewed). Prior-30-day spend correlates ~0.6 with order value - the same number the statistics course fit - so every figure reconciles across all three courses.
